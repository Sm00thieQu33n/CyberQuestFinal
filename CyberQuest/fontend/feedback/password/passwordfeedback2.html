Scenario Feedback

Why should passwords be unique?

Reusing the same password across multiple accounts can put several accounts at risk. If one website experiences a data breach and your password is exposed, someone could try that same password to access your other accounts.

Creating a unique password for each account helps limit the damage if one password is compromised. A reputable password manager can help you generate and securely store unique passwords.

What should you remember?

  • Use a unique password for every account.
  • Avoid small variations of the same password.
  • Consider using a reputable password manager.
  • Enable multifactor authentication when available.
