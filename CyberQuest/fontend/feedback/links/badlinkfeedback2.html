Why was this link suspicious?

The suspicious link was:

https://maryvllle.edu/notifications

The domain contains a spelling difference. The expected organization name is "maryville," but this link uses "maryvllle," with an extra "l."

Attackers can sometimes use small spelling changes in website addresses to make a link look similar to a legitimate website. Carefully checking the domain before signing in can help identify these suspicious links.

What should you look for?

  • Check the spelling of the domain carefully.
  • Watch for small changes to familiar website names.
  • Be cautious when a link looks almost identical to a legitimate website.
  • Verify the website address before entering your username or password.
