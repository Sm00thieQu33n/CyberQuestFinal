How to run backend of project:

Python 3 is required to run the backend.

•	Open a terminal and navigate to the backend folder: cd backend
•	Run: pip3 install fastapi uvicorn
•	Run: python3 -m uvicorn main:app –reload

How to run frontend of project

•	Open frontend/index.html.
•	Right-click the file.
•	Select Open with Live Server.
•	The CyberQuest login page should open in your browser.
